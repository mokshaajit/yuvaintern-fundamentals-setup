# Yuvaintern Full Stack Developer Internship Project

## About the Project

This project was developed as part of the Yuvaintern Full Stack Developer Internship. The purpose of this project is to understand the fundamentals of full stack development, configure the development environment, practice Git and GitHub workflows, and create a basic frontend and backend application.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Git
- GitHub
- Visual Studio Code
